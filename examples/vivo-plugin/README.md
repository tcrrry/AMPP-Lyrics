# vivo 系统播放器扩展 0.2-preview.3

本版配合 1614 稳定性及 External Media 预览宿主，支持 Apple Music 1614 普通版与共存版，并保留 1613、1609 External Media 宿主支持。作者原版 1614 嵌入版没有本扩展的 External Media API 和服务声明，单独导入 ZIP 无法补齐。

公开入口只依赖原有 SDK v1，检查扩展 API 后才加载实现。原版宿主可显示明确的配套宿主要求，避免先报 VivoMediaPlugin 入口类找不到。JVM 隔离旧 SDK 加载探针已验证；不等于实机验收。

在 AM++ 插件管理器覆盖导入 ZIP，保留原有设置；不要安装构建过程中生成的 compiler APK。安装配套宿主、导入并启用插件后，按管理器提示正常重开 AM。

- 沿用 AM 原生会话，提供歌词、循环方式与当前播放队列。
- 收藏与已下载使用 AM 原生资料库，查询可用后才声明入口。
- 发音、原文、译文的显示顺序及空行分组继续保留；可选只显示原文，以便原子岛的一行显示。
- 循环与队列能力跟随 AM 当前真实能力，电台可能限制原生控制。
- 沿用延迟连接授权与启动恢复，客户端包名和 UID 必须对应。
- 停用后释放接口、缓存、监听和后台任务。

本次没有连接手机，没有替用户安装、重启 AM 或原子随身听。1614 上实际的循环、选曲、歌词排版与连续重开仍需验收。原子随身听可能缓存旧控制器，重开 AM 后仍不显示时可手动刷新原子随身听进程。
