# AM++ Lyrics v1.5

基于用户验收通过的 v1.5-test-r7 发布，Apple Music 7.0.0-beta / 1606，模块 1.5 / 145。同步提供普通 APK、共存 APK、APKS 和独立模块 APK，保留所有历史版本。

- 修复最后一句结束后的拖动、尾奏回退和单曲循环聚焦恢复。
- 质量优先按 AM 原生 → AM++ 适配库 → 第三方；逐字优先优先使用 AM 原生／AM++ 真实逐字，否则第三方逐字权重高于译文和发音。
- 保留原生正文和逐字时间，可从 QQ／网易云补齐译文，最后机翻补缺。现有原生或 AM++ 歌词自带译文优先保留；没有另外实现 AM++ 译文单独补原生正文的链路。
- 突出发音可沿用原文逐字时间，支持原生嵌套样式时间读取；不能对齐的句子局部回退，保留其他句子的逐字，不伪造音节时间。
- 辉光灵敏度最高 500%，短单元平滑默认开启并可应用于发音。上方辅助文字保持暗色，译文留在原生容器。
- 单击来源继续查找可用源，双击不执行操作，长按进入独立歌词设置；“当前源选择最佳结果”和“恢复自动选源”分别操作。
- 优化独立设置页布局、发音设置和二级菜单，保留完整“查看当前匹配信息”，移除测试标识和开发日志入口；改进首次进入原生设置的首帧交接。

普通版保持包名、宿主版本和 NPatch 签名，可覆盖已有对应增强版；共存版使用独立包名。请覆盖安装，不要卸载或清除数据，以保留已下载歌曲。下载与校验文件对应同一发布；自动化结果见 v1.5-validation.json。

用户已验收普通测试版的核心歌词表现；本次四种包均经过构建和静态校验，共存版与 APKS 尚未逐一完成本次真机测试。独立插件仍是单独的开发工作，本次不把其兼容验证原型作为完整插件发布。
