# AM++ Lyrics v1.6

基于 Apple Music 7.0.0-beta / 1606，四种完整安装包同步移植独立插件 1.0.4 的歌词修复。模块版本 1.6 / 150。

- 新增日语字词对应发音，改善原生发音与词典补注的对齐、多行换行、重叠和行距；无法可靠对齐时保留整行发音。
- 修复逐字高亮只走一半、句末突然补亮、多行提前亮起、英文及突出发音中的字母提前亮完。
- 单曲循环使用短距离动画回到第一句，避免整首歌词长距离滚动的卡顿。
- 修复自传歌曲 ID 被资料库异步回写后，歌词长时间加载、匹配成功但不显示或无法同步播放的问题；页面与实时队列核对后才恢复绑定。
- 保存主动隐藏发音的选择，处理原生辅助文字中的转义标记。

在 Tcrrry 歌词设置中开启“字词对应发音”；默认保留整行发音，循环复位默认开启。完整安装包按原安装方式更新，重启应用后生效；不需要再次导入插件 ZIP。

验证：移植基线 r15 已在 vivo V2359A / AM++ 105 嵌入版完成抽样实机检查。v1.6 两种模块另执行整合单元测试、Lint、词典校验及四种最终安装包的签名/内容检查。实际结果见发布附件 v1.6-validation.json；插件实测范围不能等同于四种安装包均已实测。

## 完整安装包

普通 APK、共存 APK、APKS、独立模块 APK 同步更新，包名保持不变，历史版本保留。三种整合包沿用原宿主签名；独立模块 APK 使用本地模块签名，与旧版云构建签名不同，无法直接覆盖旧模块，需重装模块 APK。音乐宿主应用和下载歌曲不需要卸载。完整安装包内置离线机翻，不需要插件伴随 APK。签名、包身份、内嵌模块、原生宿主 DEX/资源与库、APKS 分包完整性分别校验；真实手机验收范围以 v1.6-validation.json 为准。
