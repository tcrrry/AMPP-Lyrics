# r6 原生逐字、译文和突出发音

## 原生逐字与平台译文

AppleMusicCustomLyricsTarget 已拥有当前歌曲信息，却只向 FallbackLyricsTranslation 传入歌曲 ID。后者另查 MediaMetadataCache，缓存缺失时不会搜索平台译文，并把空补齐结果永久缓存。r6 传入当前歌曲的歌名、歌手、专辑和时长；它们进入补齐缓存标识，后来取得信息时可以重新补齐。平台译文仍缺失时，30 秒冷却后下一次补齐调用可重试，不创建周期联网计时器。

原文匹配仍要求正规化后的完整文本一致、起始时间距离不超过 1200ms、两边都只存在一个附近候选，并拒绝对应顺序交叉。相隔较远的重复副歌可各自补译文。只补空行，不覆盖原生或先前成功的译文；原生正文和逐字时间保持原样。低置信平台结果被过滤，现有机器翻译模式用于补剩余缺失句子，来源标记保留。

## 突出发音

旧 NativeLyricsPhoneticPresentation 在切换时将原生 span 拍平，并强制 Word 改 Line。r6 复用第三方转换器已有的日语 / 韩语读音对齐逻辑。离线注音不必具有第三方逐字发音数据：通过原文字符范围找到真实时间单元，再映射到读音单元。一个时间单元涵盖多个读音时合并高亮，一个读音对应多个时间单元时使用完整时间范围。不会按字母平均拆分时间。

目前支持有完整起止时间的平坦 span；无法完整对齐、嵌套单元、背景人声和多声部保留安全回退。沿用原有整轨模式策略：任一显示读音无法完整映射时，突出发音整轨降为逐行。原文与译文不丢失，关闭突出发音从原始文档恢复。

原生突出发音与第三方突出发音沿用短单元平滑开关：仅将同句中不足 100ms 的读音与相邻单元合并，间隔不得超过 20ms，保留全部文本、空格及完整时间范围；普通英文原文的词边界仍受保护。设置说明同步调整。

## 验证范围

新增覆盖：实际报告的“心を今解いて”、离线注音完整管线、多个汉字共用读音时间、机器译文和辅助来源保留、无时间 / 嵌套回退、发音平滑开关及长停顿、重复副歌和交叉对齐、播放信息缺失后补齐、查询失败冷却后重试、低置信或不相关结果拒绝。完整测试、lint、原包接口、字典许可及最终安装包静态核验由私人工作流再次执行并导出。

测试使用本地夹具与离线词典；没有把模拟测试标为实际歌曲在线命中，也没有真机验证动画。r5 聚焦恢复入口不修改。独立插件 0.1.0 仍不含本次应用内修改。
