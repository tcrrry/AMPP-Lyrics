# AM++ Lyrics v1.3 · Apple Music 7.0.0-beta

跟进原作者对 **Apple Music 7.0.0-beta / 1606** 的适配，修复原生设置页缺少 **Tcrrry 歌词设置** 入口的问题。本次同时提供普通 APK、APKS、独立模块与共存 APK。

## 更新内容

- 原生设置页同时显示 **AM++** 和 **Tcrrry 歌词设置**；两个入口分别打开各自的页面，返回或重建不会重复添加。
- 适配 7.0 的设置、歌词、播放器、元数据和玻璃／双栏接入，包含上游最新的平板横竖屏切换修复。
- 保留 QQ／网易云等歌词匹配、逐字歌词、译文、发音和手动换源；更新额外发音字幕在 1606 中的内部类、方法及布局。
- 普通版与共存版新安装默认开启自定义歌词替换、自动歌词；已有保存的关闭选择保留。
- 无真实逐字计时的歌词逐行显示，配色选项位于设置页末尾。
- 共存版更新到相同的 7.0 宿主，修正新适配框架中的包名识别，保留资料库导航布局修复及资源／Provider 隔离。

## 下载与安装

展开本页下方 **Assets**：

| 文件 | 用途 |
| --- | --- |
| **AMPP-Lyrics-AppleMusic-7.0.0-beta-arm64.apk** | **普通整合版，推荐。** 直接打开安装，无需 Root、LSPosed 或另外安装模块。 |
| AMPP-Lyrics-AppleMusic-7.0.0-beta-arm64.apks | 普通分包版，用 MT 管理器／SAI 等分包安装器完整安装，不要改后缀或只安装 base。 |
| AMPP-Lyrics-module.apk | 独立模块，供兼容的模块环境或自行嵌入，不是 Apple Music 主程序。 |
| AMPP-Lyrics-AppleMusic-7.0.0-beta-arm64-coexist.apk | 共存整合版，显示为 **AM++ Lyrics 共存版**，可保留官方版或普通版。 |

`.sha256` 用于校验；`.validation.json` 是构建证据，均不需要安装。整合包要求 **Android 11+、arm64**；原始分包密度为 xxhdpi，不是全架构通用包。

普通版与本项目既有普通整合包使用同一签名，共存版与旧共存版使用同一签名，可先尝试覆盖升级。普通版不能直接覆盖官方签名的 Apple Music；卸载会删除本地数据和下载音乐。请先导出重要的模块设置和歌词。分包与单 APK 互换时，应完整替换安装形态，不要仅替换 base。

共存版使用独立数据目录，请从自己的图标登录，不接管外部音乐链接及第三方音乐 SDK 认证入口。普通版与共存版各自保存设置。
