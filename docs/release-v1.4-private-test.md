# v1.4 私有测试 r17

普通单 APK，Apple Music 7.0.0-beta/1606。

针对每次启动第一次进入设置黑屏的反馈，将旧玻璃捕获／首帧阻挡释放提前至原生 Compose 设置页开始构建，且不再依赖设置项绑定成功。未附着的根视图会等窗口附着后再重绘；AM++ 对话框显示时也请求首帧布局。冷启动模型尚未准备好的回归场景已覆盖，实际黑屏是否消除仍需手机确认。

AM++ 设置中新增“歌词辉光增强”下的“辉光灵敏度”和“辉光触发位置”。灵敏度 50%～200%，100% 为当前规则；可选全部长音、仅句尾、句尾优先，默认全部长音。修改保存后对后续词生效；增强总开关仍需重开 Apple Music。词位置取原生歌词时间，跳过标点与零时长词；不分析人声。高灵敏度打开较短单字／英文词辉光时，将辉光自身时长按真实词时长恢复，生成逐字渐变前恢复共用元数据，不修改逐字扫光入参或音频。

固定原包的辉光没有仅句尾限制。它要求前景词块累计时长至少 1 秒、字符数最多 7，并受文字分类、分组及已有动画限制。当前适配另放开中日韩单字和长英文词。详细规则见 docs/lyric-glow-1606.md。

保留 r16 的 100 毫秒交接微调、末字保护、3.5 秒清晰浏览和平滑回位。专辑／歌词页切换问题按用户要求暂停继续修改；保留已有实现。

手机重点：彻底关闭再启动后第一次进入原生设置／Tcrrry 歌词设置，及第二次对比；同一首歌对比灵敏度 50%、100%、200% 与三种位置，确认末字、逐字节奏和聚焦仍正常。若首入黑屏仍存在，诊断增加 settings-handoff；辉光记录 glow-policy、glow-gate、glow-result，无正文和自动上传。

私有预发布，不改公开 main、v1.3、共存版或 APKS；保留所有历史发布与附件。测试／构建通过后生成包，手机表现尚未验证。
