# AM++ Lyrics v1.9

发布日期：2026-10-17。Apple Music 7.0.0-beta /1609，Android 12+、arm64。四种安装形式同步更新，历史附件不替换。

- 内嵌正式 Tcrrry Lyrics Plugin 1.0.8，同一份 code.jar，只将检查更新频道设为主项目 1.9。同步近期署名过滤、QQ 完整歌词回退、中文冷启动来源按钮、操作说明、轻量开关和翻译界面升级。
- 主项目离线机翻仍为内嵌 ML Kit，不需要伴随 APK。语言包管理改用插件统一磨砂小窗，支持中文、English、代码搜索；显示下载状态，下载所选语言与中文、删除所选包、失败恢复。英文作为中转不创建/删除虚构模型。
- 融合播放模式插件。设置改名“强制覆盖循环方式”，默认开启；只改名称，不改变已测试行为、保存键和安全边界。请停用单独的播放模式插件。
- 保留设置页两个入口的材质差异、轻量玻璃、来源滚动、同曲内容过渡，以及共存路由、专辑背景和 vivo 原生播放器发现声明。

## 升级

选择同一种形式覆盖安装，不先卸载音乐应用。保留配置、迁移标记、用户禁用/删除状态和更高版本插件。普通增强 APK 不能覆盖不同签名的官方 Apple Music。主程序和插件的检查更新分别指向自己的正式发布。

## 验证与限制

preview.8 中文歌方形入口由用户确认已恢复。正式内嵌语言包 UI 通过自动交互、异步状态与紧凑宽度渲染检查，未新增手机模型下载/网络验收。四种主项目安装包均为新构建，不借用插件测试冒充四包实测。

打包验证最终签名、身份、内嵌插件、宿主 DEX/资源/原生库、分包完整性，及最终共存 APK/origin 的 vivo 发现声明。沿用[共存播放器回归门禁](COEXIST-PLAYER-REGRESSION-PREVENTION.md)，系统权限由用户管理，不承诺共存版原子岛。

保留[QQ 逐字截断实际样本](QQ-INCOMPLETE-1669861760.md)和[无正文歌曲持续加载证据](NO-LYRICS-SPINNER-1807802486.md)。署名过滤不能保证所有未知格式都识别；个别无正文歌曲持续加载仍未解决。最终结果见 v1.9-validation.json 和 SHA256SUMS.txt。
