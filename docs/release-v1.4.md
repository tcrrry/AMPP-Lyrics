# AM++ Lyrics v1.4 · Apple Music 7.0.0-beta

本次同步提供普通 APK、共存 APK、APKS 与独立模块。基于 Apple Music 7.0.0-beta / 1606；模块内部版本 1.7.0 / 137。

## 更新内容

- Tcrrry 歌词设置与原 AM++ 设置分开。我们的歌词源、译文、发音及辉光控制在 Tcrrry 页面；辉光增强开关、50%～200% 灵敏度和全部长音／仅句尾／句尾优先均已迁入，保留已保存的值。
- 改进 QQ／网易云发音与逐字时间的对齐，补充内置日文、韩语及按歌曲指定的粤语注音；来源自带发音优先。未提供逐字时间的歌词保持逐行显示。
- 改进换源、拖动进度、重播后的歌词聚焦与末字扫光保护；手动浏览期间保持清晰，停止操作 3.5 秒后平滑回位。保留 100 毫秒行交接微调。
- 针对首次进入设置黑屏，提前释放旧画面首帧阻挡，并在窗口附着后重绘。
- 缩短歌词来源状态描述，并为滚动边界增加渐变。
- 正式版移除复制诊断、匹配输入调试入口及测试标记，关闭测试诊断采集。正常的来源匹配历史、预览与 API 连接检查保留。

辉光按歌词时间、字数和词块布局触发，不分析歌声；“仅句尾”按歌词位置判断。完整规则见 [辉光规则](https://github.com/tcrrry/AMPP-Lyrics/blob/v1.4/docs/lyric-glow-1606.md)。

## 下载与安装

展开下方 Assets，选择一种安装方式：

| 文件 | 用途 |
| --- | --- |
| **AMPP-Lyrics-AppleMusic-7.0.0-beta-arm64.apk** | **普通整合版，推荐。** 直接安装，无需 Root 或另外安装模块。 |
| AMPP-Lyrics-AppleMusic-7.0.0-beta-arm64-coexist.apk | 独立包名的共存版，可保留官方版或普通版。 |
| AMPP-Lyrics-AppleMusic-7.0.0-beta-arm64.apks | 分包版，使用 MT 管理器／SAI 等完整安装，不要改后缀或只安装 base。 |
| AMPP-Lyrics-module.apk | 独立模块，供兼容模块环境或自行嵌入，不是 Apple Music 主程序。 |

整合包要求 Android 11+、arm64，保留原 xxhdpi 分包资源。`.sha256` 与 `.validation.json` 是校验资料，无需安装。普通版和共存版各自沿用原签名，可先尝试覆盖本项目相应版本；普通版不能覆盖官方签名版本。独立模块延续原安装身份，内部版本号递增；单独安装模块时需确认新旧签名，不能保证跨构建覆盖安装。

## 验证与已知限制

普通及共存模块分别执行单元测试、Lint 和构建；打包验证宿主接口、发音资源、签名、包名、内嵌模块、原始 DEX、资源和原生库。实际测试数量、源码提交及附件校验值见 `v1.4-validation.json`。

用户已认可普通 r17 的改善；新设置位置与四种正式包尚未完成完整手机验收。偶发歌词页专辑／歌名停留在上一首的现象仍在排查，本版保留已有恢复逻辑。首次设置黑屏已覆盖冷启动回归场景，仍欢迎实机反馈。宿主本身是 7.0 beta，不代表其他 7.x 已适配。

v1、v1.1、v1.2、v1.3 及所有历史测试版本和附件均保留。
