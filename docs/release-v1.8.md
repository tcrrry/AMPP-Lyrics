# AM++ Lyrics v1.8

发布日期：2026-10-14。Apple Music 7.0.0-beta / 1609，Android 12+、arm64。

- 内置 Tcrrry Lyrics Plugin 1.0.7：字词对应发音自然填行，修复缓存重复失效；缓存默认 64 MB，可设置 0–1024 MB并按最近使用替换，支持单独清理生成歌词与匹配记录。
- 同曲歌词、翻译与发音更新保留旧内容至结果就绪，相同内容复用，实际替换采用淡化/模糊过渡。
- 修复共存版设置玻璃失效，设置入口与 AM++ 总设置平行；偏好调整不再重置首页来源滚动。保留二级小窗、磨砂材质、进入/退出动画与更新提醒。
- 恢复共存身份路由，修复播放页灰色背景。恢复 vivo 原生播放器服务发现声明，并在正式打包时验证最终 APK 与内嵌 origin，避免测试修复未进入发布包。
- 普通 APK、共存 APK、APKS、模块 APK 同步发布。旧发布和附件保留；内置离线机翻不需伴随 APK。

## 升级

选择与已安装版本相同的形式覆盖安装，不要先卸载音乐应用。普通 APK 与官方 Apple Music 同包名但签名不同，不能覆盖官方版。共存版可保留官方版。APKS 必须完整安装分包；模块不是音乐主程序。保留插件配置、原有迁移标记、用户禁用/删除状态，不降级用户更新的插件。

## 验证与限制

四种最终产物检查签名、身份、嵌入插件、宿主 DEX/资源/原生库与分包完整性。结果见 `v1.8-validation.json` 和 SHA-256 校验文件。

共存路由预览的背景恢复已获用户确认；vivo 预览的原生播放器显示和服务绑定已在 vivo V2359A 检查，未点击验证播放控件。本次正式四包是新构建，不等于四种形式均新增实机验收。系统通知权限和原生播放器开关仍需允许；不静默修改手机权限。

**共存版不承诺原子岛显示或歌词。** 普通媒体通知、vivo 原生播放器和原子岛是独立能力。回归防护与历史证据见 [播放器修复说明](COEXIST-PLAYER-REGRESSION-PREVENTION.md)。

**少数无正文歌曲可能持续加载，本版未修复。** 已记录歌曲 1807802486 的现场与 QQ/网易云公共接口响应摘要，见 [异常证据](NO-LYRICS-SPINNER-1807802486.md)。不把无可用歌词简单归因于网络或 Apple 服务器，不放宽匹配造成误配。
