# AM++ Lyrics v1.11

基于 AM++ 1.6.8 与 Apple Music 7.0.0（1614），内置歌词插件 1.2.1 和翻译插件 1.0.0。

**稳定性修订**：四种主项目附件已更新，保留同一版本及签名。更新前的附件以 `before-stability` 名称保留；v1.11 原标签不重写，修订源码请以本页附带的源码补丁及仓库主分支为准。

新增受限的原生资源异常恢复、旧版玻璃二进制接口，以及可选的 vivo External Media 服务。要使用 vivo 歌词、循环和队列功能，需额外导入并启用本页的 vivo 插件 ZIP。独立模块不能单独添加宿主 APK 服务声明。启动主题的 TypedArray 资源恢复仅在可取得明确的 AM 色彩资源 ID 时尝试；不能保证消除全部闪退。

- 合入 1614 歌词插件适配、多演唱者发音突出状态、译文对齐与此前保留的预览修复。
- 强制覆盖循环方式改为识别页面播放／随机按钮；点单首歌曲不会仅因插件观察到队列替换而自动清除单曲循环。
- 更新内置插件版本判断，旧版本可按原安装规则升级；保留宿主自动补词与手动歌词的用户设置，不再由内置插件强制屏蔽。
- 保留共存路由、独立歌词设置、可选翻译插件和 vivo 媒体服务发现声明。

四种安装包通过宿主接口、签名、身份、嵌入模块、资源及分包完整性检查；共存 APK 与其内嵌原包通过 vivo 服务发现声明检查。主要模块单元测试通过。最终发布包、宿主补词与插件并用、vivo 控制及原子岛**未完成新的实机验收**；共存版不承诺原子岛支持。详见 `v1.11-validation.json` 与各附件 SHA-256 文件。

普通版与官方版包名相同但签名不同。升级前请核对签名，不要为安装直接卸载音乐应用。APKS 必须使用支持分包的安装器完整安装。
