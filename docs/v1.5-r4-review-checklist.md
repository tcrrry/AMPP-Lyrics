# v1.5-test-r4 用户意见核对

本次仅私人测试单 APK，公开 1.4 与四种正式安装包不变。先前完整需求与验证边界保留在 [r3 核对表](v1.5-r3-review-checklist.md)。

| 用户意见 | 实现与验证 | 仍需设备确认 |
| --- | --- | --- |
| 尾奏首次回拖、单曲循环停在末尾 | 独立 MediaBrowser 时钟检测回退 / 跳转；显式处理当前位置、解除跟随锁、取消旧歌词消息并重排。`LyricReplayRecoveryTest`、`NativeLyricsPlaybackClockTest`、`NativeLyricsImmediateAnchorTest` 覆盖无原生回调、拖动延后、暂停、片头空白、旧歌曲拒绝与不清除其他消息 | 500ms 观察间隔、真实设备循环与首次回拖时序 |
| 500% 是否真的生效 | `LyricGlowScopeTest` 覆盖 200ms 短音提升门控后动画 1000ms→200ms、延时 500ms→100ms，同时还原真实逐字时间。原包 A.V 门控及动画取值已静态核对 | 实际视觉与不同曲目的触发次数 |
| 逐字权重最高 | 同歌曲可信度档内有效逐字高于译文 / 发音；原生逐字→作者库逐字→第三方，质量优先顺序保留。现有排序与偏好回归 | 不降低身份可靠性要求，不保证所有歌有逐字 |
| 三种发音同一窗口 | 日语 / 韩语 / 粤语同卡片，独立开关与保存键保留；`TcrrrySettingsLayoutAndroidTest` | 窄屏和大字体设备观感 |
| 长摘要挤压重叠 | 摘要两行截断、完整匹配信息可查看，来源操作行随内容增高；窄 300dp 布局回归校验边界无重叠 | 系统最大字号仍需观察 |
| 播放源手势说明 | 当前匹配信息旁写明单击切源、双击无操作、长按详细设置；布局回归 | 沿用 r3 触摸处理 |
| 平滑默认开、红色选中、移入辉光 | 未设置默认为开，已关闭保留关闭；红色 chip 在辉光卡片；UI 点击 / 默认 / 持久化回归 | 实际歌词动画效果 |
| 删除辉光总开关 | 移除 UI，总增强在已验证宿主始终安装；保留历史配置键兼容；`CjkKaraokeAnimationFeatureTest` 覆盖旧关闭值不会禁用 | 不支持的宿主仍拒绝安装 |
| 二级菜单统一气泡 | 匹配信息、源选择、历史 / 预览、API 配置列表、辉光时机与语言选择采用圆角可滚动卡片；匹配信息可选择复制 | 编辑文本及危险确认仍使用标准对话框 |
| 首三卡合并 | 歌曲、偏好、来源合并；平滑独立移至辉光；布局回归 | 真机截图 |

测试通过与签名 / 摘要 / 原包接口检查不能替代真机验证。单 APK 沿用原包身份与签名，不卸载或清数据；首次设置黑屏没有本次新修正，独立插件仍仅部分兼容功能。
